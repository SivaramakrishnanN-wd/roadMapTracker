# RoadmapTrack

A browser-based tracker for a 90-day interview-preparation roadmap.

The app shell includes Dashboard (`/`), Daily (`/daily` and `/daily/:date`),
and Syllabus (`/syllabus`) routes. Use Settings to switch between light, dark,
and system themes.

## Development

Requires Node.js 20+ and npm.

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run typecheck
npm run test
npm run build
```
